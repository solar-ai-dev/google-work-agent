# v1.8 Ambiguity Review Sample

1. `김 대리 건 처리해줘` + 세 명 후보 → 후보 회사/업무 차이를 보여주고 사람 선택. 사람 선택 후에도 `처리`가 불명확하면 원하는 작업을 최소 질문으로 확인.
2. `그대로 진행해줘` + 직전 승인 대기 Plan 존재 → 불필요한 clarification 금지, 직전 Plan 의미 상속.
3. `이 메일 답장해줘` + 선택 Thread → SEND 의도. Draft 여부 질문 금지. 최종 내용 고정 후 승인.
4. `답장 초안만 써줘` → Draft 의도. SEND 금지.
5. `다음 주 화요일 오후에 회의 잡아줘` → duration 질문.
6. `Task 만들어줘` + 기본 Task List → due date가 없다는 이유로 질문하지 않음.
7. `다 같이 답장해줘` → Reply-all recipient scope 후보를 보여주고 확인.
8. `매주 월요일 스탠드업을 10시로 바꿔줘` → occurrence/series가 불명확하면 질문.
9. `1~3일 워크샵 안에 2일 내부 미팅` → 관련 nested overlap으로 진행, 충돌 질문 금지.
10. `워크샵 중간에 고객 미팅` + 관계 근거 없음 → nested relation인지 conflict override인지 질문.
